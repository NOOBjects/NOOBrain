# NOOBrain

App para aprender qualquer tema: trilha de conceitos, lição guiada, tutor, cartões e revisão espaçada. Estúdio NOOBjects. No ar em https://noobrain.vercel.app.

```bash
npm install
npm run dev     # http://localhost:3000
```

Regras e mapa do código: `CLAUDE.md`. Roteiro: `PLANO.md`. Variáveis: copiar `.env.example` para `.env.local`.
